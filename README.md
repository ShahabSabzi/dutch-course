# Nederlands Lessen

Dutch course app for iPhone and desktop. Lessons 1 to 5, each with a dialogue, word list, grammar, exercises and a test. A final exam mixes questions from all lessons. Progress is saved in the browser.

## Put it on GitHub Pages

1. Settings > Pages. Under Build and deployment, set Source to Deploy from a branch, branch main, folder / (root). Save.
2. Open https://YOUR-USERNAME.github.io/dutch-course/ in Safari.

## Edit lessons

All content is in data/lessons.js. After any change, reload the page. Progress stays saved in this browser.
